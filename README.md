# BinaryLab — Лабораторна робота №4 (Числа з плаваючою комою)

Цей проєкт є інтерактивним калькулятором для роботи з числами у двійковому представленні з плаваючою комою. Застосунок автоматизує процес переведення чисел у модифіковані коди та виконує додавання мантис.

## 🚀 Особливості

- **Розрахунок модифікованих кодів:** Прямий, зворотний та додатковий коди для мантис.
- **Візуалізація додавання:** Демонстрація операції додавання мантис у стовпчик (модифікований додатковий код).
- **Динамічний інтерфейс:** Миттєве оновлення результатів при зміні вхідних даних (Варіант 7).
- **Типізація:** Повна підтримка **TypeScript** для надійності розрахунків.

## 🛠 Технологічний стек

- **React (Vite)**
- **TypeScript**
- **Lucide React** — для іконок.
- **CSS Modules** — для ізольованої та чистої стилізації компонентів (BEM approach).

## 🏗 Архітектура

Проєкт розроблений з дотриманням принципів **Atomic Design**:

- Розподіл логіки на чисті функції для розрахунку бінарних кодів.
- Використання типізованих інтерфейсів для обробки станів результатів.

## ⚙️ Логіка обчислень

Програма реалізує:

1. Виділення знакових розрядів (модифікований код використовує 2 біти для знаку: `00` — плюс, `11` — мінус).
2. Формування оберненого коду шляхом інверсії мантиси.
3. Формування додаткового коду шляхом арифметичного додавання одиниці до молодшого розряду.
4. Додавання в модифікованому коді з урахуванням переносів.

## 🏗️ Опис структур даних (Interfaces)

Для забезпечення типізації та уникнення помилок при роботі з двійковими рядками використовуються наступні інтерфейси:

### 1. Коди мантиси

Описує три стани представлення числа в пам'яті комп'ютера.

```typescript
export interface MantissaCodes {
  direct: string; // Прямий код (знак + значення)
  inverse: string; // Зворотний код (інверсія бітів для від'ємних)
  complement: string; // Додатковий код (основа для додавання)
}
```

### 2. Результат обчислень

Глобальний об'єкт, що агрегує всі дані для відображення в інтерфейсі.

````typescript
export interface CalculationResult {
    exp: string; // Порядок числа (Експонента)
    A: ExtendedCodes; // Об'єкт першого операнда (коди + знак)
    B: ExtendedCodes; // Об'єкт другого операнда (коди + знак)
    C: {
    mod: string; // Сума мантис у модифікованому коді
    c10: string; // Результат у десятковій системі (Base-10)
    };
}
```
## 🧠 Логіка програми (Core Logic)
Нижче наведено розбір ключових алгоритмів, реалізованих у файлі BinaryLab.tsx.

### 1. Генерація модифікованих кодів
Функція getCodes відповідає за створення модифікованого додаткового коду. Використовується два знакові розряди (00 або 11).

```typescript
const sign = isNegative ? "11" : "00"; // Модифікований знак
const direct = `${sign},${mantissa}`; // Формування прямого коду

// Алгоритм отримання додаткового коду (для від'ємних чисел)
let carry = 1; // Додаємо 1 до молодшого розряду зворотного коду
let compM = "";
for (let i = inverseM.length - 1; i >= 0; i--) {
const sum = parseInt(inverseM[i]) + carry;
compM = (sum % 2) + compM; // Результат розряду
carry = sum > 1 ? 1 : 0; // Перенос у наступний розряд
}
```
### 2. Двійковий суматор
Функція addBinary імітує роботу апаратного суматора, виконуючи додавання "у стовпчик" із врахуванням розділової коми.

```typescript
const addBinary = (s1: string, s2: string): string => {
let carry = 0;
let res = "";
// Видаляємо візуальну кому для проведення обчислень
const a = s1.replace(",", "");
const b = s2.replace(",", "");

for (let i = a.length - 1; i >= 0; i--) {
const sum = parseInt(a[i]) + parseInt(b[i]) + carry;
res = (sum % 2) + res; // Біт результату
carry = sum > 1 ? 1 : 0; // Перенос
}
// Повернення коми на місце після двох знакових розрядів
return res.substring(0, 2) + "," + res.substring(2);
};
```
````
